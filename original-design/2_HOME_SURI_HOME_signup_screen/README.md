# HOME SURI HOME 회원가입 1단계

## 구성 파일

- `signup.html` : 회원가입 1단계 화면
- `signup.css` : 회원가입 전용 스타일
- `signup.js` : 이메일 인증 및 입력 검증
- `common.css` : 공통 프레임, 헤더, 하단 네비게이션
- `common.js` : Lucide 아이콘 및 토스트
- `assets/signup_room.png` : 시안에서 추출한 거실 이미지

## 실행

`signup.html`을 브라우저에서 열면 됩니다.

로그인 화면의 회원가입 링크는 아래처럼 연결하세요.

```html
<a href="signup.html">회원가입</a>
```
