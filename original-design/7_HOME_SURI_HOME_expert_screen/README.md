# HOME SURI HOME 전문가 찾기 화면

## 구성 파일

- `expert.html` : 전문가 찾기 화면 마크업
- `common.css` : 공통 앱 프레임, 헤더, 하단 네비게이션
- `expert.css` : 전문가 화면 전용 스타일
- `data.js` : 카테고리 및 전문가 데이터
- `common.js` : 아이콘 초기화와 토스트 기능
- `expert.js` : 카테고리, 검색, 버튼 인터랙션
- `assets/` : 화면 이미지 자산

## 실행 방법

`expert.html`을 브라우저에서 열면 됩니다.

## 프로젝트에 합칠 때

페이지 폴더를 `Publishing/HOME_SURI_HOME_expert_screen/` 안에 넣고,
상단 및 하단 링크 주소만 실제 프로젝트 경로에 맞게 수정하면 됩니다.
