# HOME SURI HOME 사진 흐림 안내 팝업

## 포함 파일

- index.html
- blurry-modal.css
- blurry-modal.js
- assets/blurry-beaver.png

## 동작

- 다시 촬영하기: 모바일 카메라 입력 열기
- 사진 선택하기: 갤러리 파일 입력 열기
- 바깥 배경 클릭 또는 ESC 키로 닫기

## 기존 페이지에 연결

팝업을 표시할 버튼에 아래 ID를 사용합니다.

```html
<button id="openBlurryModal" type="button">
  사진 흐림 팝업 열기
</button>
```
