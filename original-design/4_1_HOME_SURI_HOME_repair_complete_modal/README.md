# HOME SURI HOME 수리 완료 팝업

## 포함 파일

- index.html
- complete-modal.css
- complete-modal.js
- assets/complete-beaver.png

## 동작

- 나중에 할게요: 팝업 닫기
- 후기 작성하기: 후기 작성 화면으로 이동
- 바깥 영역 클릭 또는 ESC 키로 닫기

## 기존 페이지에 연결

버튼에 아래 ID를 적용합니다.

```html
<button id="openCompleteModal" type="button">
  수리 완료 팝업 열기
</button>
```

후기 작성 페이지 경로는 `complete-modal.js`에서 변경할 수 있습니다.
